# Game Boy Wars 3: Ghidra study pack

Start with Game-Boy-Wars-3-Ghidra-Study-Guide.md.

GBW3StudyBookmarks.java is an optional Ghidra script that adds 18 study bookmarks to the reviewed program. Installation and use are described in the guide. It checks the mapped ROM hash before editing and preserves existing annotations.

verification.json records the isolated routine checks and bookmark-script validation performed on a copy of the supplied GZF. No game ROM or Ghidra installation is included.
