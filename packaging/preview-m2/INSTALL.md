# Installation

Use a clean/disposable Ghidra 12.1.3 distribution with JDK 21. Remove any previous
GhidraBoy extension, install `GhidraBoy-extension.zip` through File → Install
Extensions, and restart. Do not mix an old GhiGBC/game-specific provider into the
acceptance installation.

The preview contains no emulator dependency and no private target material.
