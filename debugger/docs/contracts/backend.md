# Execution adapter contract — initial version 1

`ghigbc.backend` is a small Python protocol and immutable records. Importing it, the profile API, the agent or the display module does not import an emulator adapter or load its library. Backend selection is explicit through `create_backend`; the only installed implementation currently offered is SameBoy. Unknown names fail before reading ROM inputs. Native bindings and structure layouts remain private to the adapter.

An immutable descriptor identifies the core/configuration/patch, actual hardware model and cartridge operating mode, supported models/mappers, capabilities, observation precision and timebase. A snapshot retains the descriptor that applied when it was captured. Current SameBoy support is CGB-E, including DMG-cartridge compatibility mode; this does not establish native DMG hardware support.

The generic agent consumes `cpu_bytes`, `mutable_banks()`, `unknown_cpu_ranges`, named stop reasons, register/state observations and immutable event records. It never interprets the SameBoy ABI's flattened memory buffer. `ghigbc.native` remains an explicit compatibility import for existing SameBoy callers, including its native test surface and `Capture.memory`; that legacy representation is not part of the new snapshot protocol.

Physical region codes retain existing trace-schema-1 identities. Backends normalize their own region enums into this vocabulary. Event `origin_name` and `precision` describe actual observations; publication does not assign CPU provenance or instruction-final precision to every future backend. Unsupported/unobserved CPU ranges are marked unknown by the adapter's capture coverage.

Ticks have a declared frequency, or an explicitly unavailable timebase. Generic pacing uses that frequency rather than assuming an emulator clock. Traces add `Backend`, `BackendAPI`, `Model`, `HardwareMode`, `Capabilities`, `Ticks` and `TicksPerSecond`; existing paths and schema-1 fields remain readable. The old `Ticks8MHz` field is populated only for a matching timebase. These additive attributes do not change the native ABI or checkpoint payload version.

`Button` defines semantic input order: right, left, up, down, A, B, select, start. An adapter must translate this into its own engine's key order. `key_mask()` uses the same contract order. Frame buffers are immutable ARGB8888 data with explicit dimensions; the SDL presentation layer uses backend methods and owns its own SDL handles. Video and input require declared capabilities.

`ghigbc.session.Session` owns session UUIDs, public capture/epoch counters, execution policy, recovery metadata and edit auditing. Native adapters implement the hardware hooks and opaque payload save/load operations. Their native locks remain internal; a shared session lock keeps policy and hardware operations ordered. Pause does not wait behind that lock. Close is terminal and happens after owner/display workers stop; late pause is harmless and ordinary reads reject a closed backend. Concurrent destruction while another caller uses the machine is not supported.

Backend observations are frozen dataclasses implementing `Snapshot`. The session stamps immutable context and event data without interpreting or copying their memory layout. Native hardware mapping generations stay distinct from public session epochs. Restore increments the public epoch; ordinary capture increments the public capture ID.

The generic checkpoint envelope is schema 3 with explicit backend, model, mode, timebase and payload filename. SameBoy's small compatibility identity hook continues writing/reading schema 2, retaining the old core/config/patch/ROM/boot/model checks. New optional metadata is additive, and an actual pre-refactor schema-2 fixture is verified against the new reader. Restore hashes a private payload copy and loads that same copy, so a later replacement of the original cannot change the restored bytes.

Checkpoint metadata and edit intent are atomically written and synced before mutation. Failed or partially completed writes retain recovery data, produce a failed audit, and block further execution until a valid restore. When possible the agent publishes a fresh fault capture with the actual changed bytes; it never claims that an unsuccessful write left state untouched. Ordinary input errors and unavailable capabilities are rejected before recovery creation.

`CommandQueue` owns the bounded owner-thread queue, execution-time session/epoch/selection checks, timeout cancellation and disconnect draining. A timed-out queued operation is cancelled before it can mutate the machine. An already executing operation cannot be advertised as cancelled. Internal shutdown commands deliberately avoid binding to an earlier epoch, while user actions keep their context checks. The existing ordered Trace RMI callback dispatcher remains separate.

Capabilities are checked before recoverable edits or unsupported step/input/video operations. The agent supplies the selected backend's profile capabilities to `ProfileSession`; a decoder requiring an unavailable capability is not instantiated. Existing profile API callers retain their legacy default capabilities for compatibility.

SameBoy C sources and the instrumentation patch are under `debugger/backends/sameboy/native`; build and package paths use that location. Their content and native ABI remain unchanged. Shared session code contains no SameBoy-specific paths or native handles. Remaining M4 acceptance includes broader failure/lifecycle checks and actual display/focus operations, which require an unlocked desktop. This protocol is not a claim that mGBA or external attachment is fully implemented.
