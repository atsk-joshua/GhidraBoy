## CPU coverage inventory and limits

`cpu-inventory.json` enumerates every one of the **512 encoding slots**: 256 base slots (including CB prefix and 11 undefined encodings), plus 256 CB second bytes. `DisassemblyTest` explicitly checks the 255 non-prefix base decode expectations, and separately checks all CB operands/lengths. The persisted-constructor fixture contains 245 base decode instances (its CB-prefix slot is one specific extended instruction) plus all 256 CB instructions, hence 501; this count must not be described as 501 unique base instructions.

Preserved exhaustive execution counts: ADC 131,072; SBC 131,072; overlapping A ADC/SBC 1,024; DAA 2,048; all CB 131,072; ADD/SUB/AND/XOR/OR/CP input pairs 393,216; ADD HL,HL 65,536; INC/DEC carry cases 1,024; signed SP add/load 131,072; accumulator rotates 2,048; LD register/memory matrix 126. Existing parameterized JP/JR/CALL/RET/RETI/RST and stack/HL wrap regressions remain. ALU, signed-stack, rotate and LD family expansions are already present in the preserved pre-integration source; this audit adds an inventory, not new opcode execution implementations.

Undefined base opcodes: D3 DB DD E3 E4 EB EC ED F4 FC FD. External vectors compare all ten architectural registers and listed final memory; only register F low nibble is normalized, not raw stack AF bytes; IME, IE and cycles are excluded. All operand permutations for every base encoding are not exhaustive. HALT/STOP/IME remain visible userops; STOP keeps one-byte static decode. Static flat-memory tests do not qualify hardware timing, runtime mapper switching, HALT bug, interrupt delay, STOP padding fetch or CGB speed switching. No universal CPU accuracy claim follows from this inventory. Coordinator should decide CPU-01 completion against this explicit preservation/expansion/inventory scope, rather than convert opcode counts into blanket accuracy.
